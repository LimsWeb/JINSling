FOR MEMBERS

회원 안내

가입 → 승인 → 날짜와 시간 선택 → 예약 확정

01 · 시작하기

가입하고 승인을 기다려요

  1. 매장에서 받은 예약 주소나 QR을 열고 회원 가입을 눌러요.
  2. 이름, 연락처, 아이디와 비밀번호를 입력하고 가입 신청을 눌러요.
  3. 첫 가입은 승인 대기 상태예요. 사장님이 승인한 후 예약할 수 있어요. 승인 상태 확인으로 다시 확인해 주세요.
  4. 다음 방문부터는 같은 아이디와 비밀번호로 로그인해요. 매번 가입하거나 승인을 다시 받을 필요는 없어요.

아이디는 영문·숫자·밑줄(_) 4–32자, 비밀번호는 12–128자예요. 1회용 초대로 가입해도 첫 승인은 필요해요. 신규 가입을 쉬는 동안에도 기존 회원은 로그인할 수 있어요.

02 · 시간 고르기

원하는 시간으로 예약해요

  1. 예약하기에서 날짜를 골라요. 매장에서 정한 예약 공개 기간 안의 날짜를 선택할 수 있어요.
  2. 예약 가능으로 표시된 시간 중 하나를 선택해요. 한 예약은 30분이에요.
  3. 필요하면 전달할 메모를 적고 예약 내용 확인을 눌러요.
  4. 날짜와 시간을 확인한 후 예약 확정하기를 눌러요. 내 예약에 확정 내역이 나타나는지 확인해 주세요.

예약 확정 내역은 내 예약에서 확인해요. 문자·카카오 알림은 자동으로 보내지 않아요. 같은 시간은 한 분만 예약할 수 있어요. 화면에서 골랐더라도 확정하기 전에 다른 분이 예약하면 저장되지 않아요. 안내를 확인하고 다른 시간을 선택해 주세요.

휴무, 운영자 차단, 점심시간 같은 반복 잠금, 이미 예약된 시간, 지난 시간, 하루 예약 한도에 도달한 시간은 선택할 수 없어요. 반복 잠금도 모든 회원의 예약 가능 시간에 함께 반영돼요. 시간표는 서울 시간 기준이에요.

03 · 예약 관리

내 예약을 확인하고 변경해요

내 예약에서 조회 시작일과 종료일을 정하고 기간 조회를 눌러요. 본인 계정에 연결된 예약만 표시돼요.

  • 메모 수정: 전달할 내용을 바꾸고 변경 내용 저장을 눌러요.
  • 예약 취소: 취소 내용을 확인하고 필요하면 사유를 적은 뒤 예약 취소하기를 눌러요.
  • 날짜·시간 변경: 기존 예약을 취소하고 다시 예약하거나 매장에 문의해 주세요. 새 시간을 확보하기 전에는 취소 후 원하는 시간의 예약을 보장할 수 없어요.

취소와 메모 수정은 매장에서 정한 취소 마감 전까지만 가능해요. 정확한 마감은 예약하기 → 나의 예약 아래 안내에서 확인해요. 마감 시각에 도달했거나 버튼이 없다면 매장에 문의해 주세요.

04 · 화면 확인

예약이 보이지 않거나 화면이 달라졌나요?

  • 예약 목록의 새로고침을 누르고 조회 기간이 맞는지 확인해요. 화면을 보고 있을 때는 30초마다 갱신해요.
  • 연결 오류 안내가 나오면 최신 상태가 아닐 수 있어요. 연결을 확인하고 다시 불러와요.
  • 전화·현장 예약은 사장님이 회원 계정에 연결한 경우에만 내 예약에 보여요. 연락처가 같다는 이유만으로 자동 연결되지는 않아요.
  • 승인 대기라면 승인 상태를 확인해요. 이용 중지 또는 가입 거절 안내가 나오면 사장님에게 문의해요.
05 · 계정 도움

비밀번호를 잊었거나 바꾸고 싶어요

잊었다면 사장님에게 문의해 주세요. 사장님이 본인 확인 후 발급한 재설정 링크를 열어 새 비밀번호를 직접 정해요. 링크는 24시간 동안 한 번 사용할 수 있어요. 만료되면 새 링크를 요청해 주세요.

현재 비밀번호를 알고 있다면 메뉴의 비밀번호 변경을 이용해요. 변경하면 다른 기기의 로그인은 종료돼요. 예전 접속키를 사용하던 회원은 예전 접속키로 시작에서 아이디와 비밀번호로 전환할 수 있어요.

비밀번호나 재설정 링크를 다른 사람에게 전달하지 마세요. 매장 관리자는 앱에서 회원 비밀번호를 조회할 수 없어요.

06 · 안심하고 이용하기

다른 회원에게 무엇이 보이나요?

회원들은 같은 예약 가능 현황을 보지만, 다른 회원의 이름·연락처·예약 메모는 보지 못해요. 내 예약에서는 본인의 예약을 확인하고, 사장님은 회원 확인과 일정 관리를 위해 필요한 정보를 확인해요.

웹 안내 카드에서는 주소를 눌러 열거나 복사하고, QR을 스캔할 수 있어요. 저장한 PNG는 이미지라 주소 클릭·복사 기능이 없어요. 같은 휴대폰에서 이용할 때는 함께 받은 예약 링크를 눌러 주세요.

예약이나 계정 문제가 해결되지 않으면 화면에 표시된 매장 문의 연락처로 연락해 주세요. 비밀번호를 보내는 대신 오류 문구와 발생 시각을 알려 주세요.

FOR THE OWNER

사장님 안내

회원 승인 · 예약 일정 · 휴무 관리 · 안내와 기록

01 · 회원 맞이하기

가입 신청을 승인해요

  1. 관리자 계정으로 로그인하고 회원 관리를 열어요.
  2. 승인 대기 회원의 이름과 연락처를 확인하고 승인을 눌러요.
  3. 승인된 회원은 본인 계정으로 예약할 수 있어요. 필요할 때 이용 중지 또는 이용 재개를 사용해요.

운영 설정 → 새 회원 가입 받기를 끄면 신규 가입을 잠시 중단해요. 기존 회원의 로그인과 예약은 계속 가능해요. 등록 계정 한도에는 관리자와 승인 대기·이용 중지·가입 거절 계정도 포함돼요.

입력한 연락처 자체가 본인 인증을 뜻하지는 않으므로 가입 정보를 확인해 주세요. 회원 상태 변경과 예약 취소는 별도 작업이에요. 기존 예약도 정리해야 한다면 예약 일정에서 확인하고 개별적으로 처리해 주세요.

02 · 방문 준비

전체 일정에서 예약을 관리해요

예약 일정에서 다가오는 예약, 하루 보기, 7일 보기로 손님 예약을 확인해요. 날짜를 이동하거나 새로고침해 최신 상태를 확인할 수 있어요.

  • 일정 · 메모 변경: 날짜, 시작 시간, 고객 이름, 연락처와 메모를 수정해요. 예약 겹침과 운영 규칙을 저장할 때 다시 확인해요.
  • 예약 취소: 예약과 사유를 확인하고 취소해요. 손님과 일정 변경을 먼저 조율해 주세요.
  • 내 계정 예약: 관리자 본인 계정으로 잡은 예약만 보여요. 전체 손님 예약은 예약 일정에서 확인해요.

문자·카카오 알림은 자동으로 보내지 않아요. 사장님의 관리 기능은 회원의 취소 마감 후에도 사용할 수 있어요. 목록을 읽는 동안 다른 사람이 수정했다면 새로고침 후 최신 내역을 확인해 주세요.

03 · 전화·현장 예약

수기 예약을 함께 등록해요

  1. 예약 일정 → ＋ 수기 예약을 눌러요.
  2. 기존 회원이면 회원 연결에서 해당 계정을 선택해요. 연결하면 손님의 내 예약에도 표시돼요.
  3. 회원이 아니면 전화 · 현장 고객 (계정 연결 없음)으로 두고 이름·연락처를 입력해요.
  4. 날짜, 시작 시간, 메모를 확인하고 예약 등록하기를 눌러요.

연락처만으로 자동 연결하지 않아요. 회원을 정확히 선택해 주세요. 수기 예약도 30분 단위이며 예약 겹침, 영업시간, 하루 예약 한도를 따라요.

04 · 쉬는 시간 정하기

하루·반나절을 한 번에 잠가요

  1. 운영 설정 → 휴무 · 시간 잠금 → ＋ 휴무 잠금을 눌러요.
  2. 시작일과 종료일을 고르고 시간대를 선택해요. 날짜는 양 끝을 포함해 최대 31일, 오늘부터 365일 후까지예요.
  3. 필요하면 잠금 메모를 적고 잠금 내용 미리보기를 눌러요.
  4. 기간, 매일 잠글 시간, 대상 날짜를 확인하고 확인한 내용으로 잠금 저장을 눌러요.

예약과 겹치면 날짜·시간을 보여주고 전체 잠금을 저장하지 않아요. 예약은 자동 취소되지 않아요. 날짜·시간을 바꾸거나 손님과 조율한 후 예약을 별도로 정리해 주세요. 미리보기 후 예약이 생겨도 저장 시 다시 검사해요.

미리보기 후 내용을 수정하면 다시 미리보기를 해야 해요. 통신 오류로 저장 결과를 확인하지 못했다면 같은 창에서 같은 내용으로 다시 저장해요. 같은 요청 번호를 사용해 중복 등록을 막아요.

05 · 잠금 해제

묶음 전체 또는 날짜 하나만 풀어요

운영 설정 → 휴무 · 시간 잠금에서 등록한 묶음을 확인해요.

  • 묶음 해제는 그 묶음에 남아 있는 잠금을 모두 해제해요.
  • 날짜별 잠금 보기 · 개별 해제 → 이 날짜 해제는 해당 날짜의 잠금 하나만 해제해요.
  • 기존에 따로 등록한 단일 잠금도 이 날짜 해제로 풀 수 있어요.

같은 날짜·시간에 두 묶음이 겹쳐 있다면 하나를 풀어도 다른 묶음은 남아요. 요일 휴무, 영업시간, 하루 한도, 기존 예약도 계속 적용되므로 잠금 해제가 예약 가능을 보장하지는 않아요. 해제 후 예약하기 화면에서 확인해 주세요.

06 · 반복하는 쉬는 시간

점심시간과 정기 휴무를 반복해요

  1. 운영 설정 → 반복 잠금을 열어요. 점심시간 설정을 누르면 매주 월~토 13:00–14:00이 미리 선택돼요. 다른 일정은 ＋ 반복 잠금으로 시작해요.
  2. 반복 방식, 시작일, 잠글 시간을 정해요. 끝나는 날이 있다면 종료일 정하기를 선택해요. 선택하지 않으면 계속 반복돼요.
  3. 반복 일정 미리보기에서 다음 적용 날짜와 겹치는 예약을 확인해요.
  4. 확인한 반복 잠금 저장을 눌러요. 저장한 규칙은 모든 회원의 예약 가능 시간에 적용돼요.

시간은 30분 단위로 선택해요. 하루 전체는 00:00–24:00으로 설정해요. 자정을 넘는 시간은 두 규칙으로 나눠 주세요. 잠금 메모는 회원에게 보이지 않아요.

기존 확정 예약과 겹치면 저장할 수 없어요. 예약은 자동 취소되지 않아요. 미리보기 후 내용을 바꾸면 다시 확인해야 하며, 저장할 때도 예약 겹침을 다시 검사해요. 미리보기에 보이는 날짜는 일부이며, 반복은 정한 종료일까지 계속돼요.

07 · 반복 잠금 조정

반복을 쉬거나 하루만 열어요

운영 설정 → 반복 잠금에서 바꿀 규칙을 찾아요.

  • 수정: 시간·요일·기간을 바꾼 뒤 미리보고 저장해요. 일시중지 상태에서 수정하면 중지 상태를 유지해요.
  • 일시중지 / 재개: 설정과 예외 날짜를 보관하면서 적용을 잠시 쉬거나 다시 시작해요. 재개할 때 기존 예약과 겹치면 적용되지 않아요.
  • 하루만 열기 → 열어 둘 날짜 → 이 날짜만 열기: 이 규칙이 적용되는 날짜 한 번만 예외로 열어요. 다른 날짜의 반복은 유지돼요. 오늘부터 365일 후까지 선택할 수 있어요.
  • 예외로 연 날짜 → 다시 잠그기: 해당 날짜의 예외를 없애요. 적용 중인 규칙은 그동안 예약이 들어왔다면 잠금을 복원할 수 없어요. 중지한 규칙은 재개할 때 다시 확인해요.
  • 전체 해제: 이 반복 규칙을 끝내요. 다시 필요하면 새 규칙으로 등록해요.

반복 규칙은 일시중지한 규칙을 포함해 최대 32개까지 등록할 수 있어요. 사용하지 않는 규칙은 전체 해제해 정리해 주세요.

하루 예외나 전체 해제는 선택한 규칙에만 적용돼요. 다른 반복 잠금, 날짜별 잠금, 요일 휴무, 영업시간과 예약 한도는 유지돼요. 변경한 뒤 예약하기 화면에서 실제 가능한 시간을 확인해 주세요.

08 · 운영 기준

영업시간과 예약 한도를 정해요

운영 설정에서 매장 이름, 공개 문의 연락처, 예약 공개 기간, 고객 취소 마감, 등록 계정 한도와 신규 가입 여부를 설정해요. 아래에서 요일별 휴무, 시작·종료 시간, 하루 예약 한도를 정하고 운영 설정 저장을 눌러요.

한 예약은 30분이에요. 빈 시간이 있어도 하루 한도에 도달하면 더 받지 않아요. 이미 확정된 예약과 충돌하는 영업시간·휴무·한도 변경은 저장할 수 없어요.

공개 문의 연락처는 회원 화면에 표시돼요. 관리자 개인 연락처와 별개이므로 손님에게 안내할 번호만 입력해 주세요. 비워 둘 수도 있어요.

09 · 예약 안내 보내기

웹 안내 카드와 QR을 나눠 써요

회원 관리 → 예약 안내 · QR을 열어요. 여러 손님에게 계속 안내할 때는 이 공용 예약 주소를 사용해요.

  • 안내 카드 링크 복사: 주소와 QR을 함께 볼 수 있는 웹 안내 카드를 전달해요. 웹에서는 예약 주소를 열고 복사할 수 있어요.
  • 이미지 저장 (PNG): 안내 카드를 이미지로 저장해 인쇄하거나 보여줘요. PNG 안의 글자는 클릭·복사 버튼이 아니에요. 메시지로 보낼 때는 클릭할 예약 링크도 함께 전달해 주세요.
  • ＋ 1회용 초대: 한 사람에게 보낼 초대 링크예요. 7일 동안 한 번만 사용할 수 있고, 사용 전에는 철회할 수 있어요. 여러 사람에게 같은 초대를 돌리지 마세요.

공용 안내와 1회용 초대 모두 가입 후 첫 승인이 필요해요. QR을 인쇄한 뒤 휴대폰으로 실제 주소가 잘 열리는지 확인해 주세요.

10 · 회원 계정 지원

비밀번호 재설정을 도와줘요

  1. 회원 관리에서 요청한 회원의 이름·아이디·연락처를 확인해요.
  2. 비밀번호 재설정을 누르고 확인해요.
  3. 한 번 표시되는 재설정 링크를 해당 회원 본인에게 안전하게 전달해요. 회원이 링크에서 새 비밀번호를 직접 정해요.

재설정 링크는 24시간 동안 한 번 사용할 수 있어요. 비밀번호를 대신 정하거나 기존 비밀번호를 조회하는 기능은 없어요. 사장님 본인 계정의 비밀번호도 메뉴의 비밀번호 변경에서 바꿀 수 있어요.

사장님이 로그인할 수 없고 재설정 링크도 없다면 유지보수 담당자에게 계정 복구를 요청해 주세요. 비밀번호·재설정 링크를 공용 채팅이나 안내 가이드에 올리지 마세요.

11 · 기록 보관

CSV로 확인하고 백업은 따로 관리해요

  • 회원 관리 → 회원 CSV 다운로드: 회원 목록을 받아요.
  • 기록 · 내보내기 → 예약 CSV 다운로드: 시작일과 종료일을 정해 해당 기간의 예약 자료를 받아요.
  • 기록 · 내보내기 → 최근 변경 기록: 최근 100건을 확인하고 변경 내용 보기를 펼쳐요.

CSV에는 이름·연락처 등 개인정보가 포함돼요. 업무에 필요한 담당자만 접근할 수 있는 곳에 보관해 주세요. 비밀번호나 재설정 링크는 CSV로 내려받을 수 없어요.

CSV는 내려받은 시점의 자료예요. 시트에서 수정해도 앱에 자동 반영되지 않고, 전체 서비스 복구용 백업을 대신하지 않아요. 운영 데이터 백업과 복구는 유지보수 담당자에게 요청하고, 복구 전에 대상 시점과 범위를 함께 확인해 주세요.

이 안내는 로그인 없이 읽을 수 있어요. 실제 회원·예약 자료는 포함하지 않아요.
