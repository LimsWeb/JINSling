# jinSling 회원 이용 가이드

로그인 화면 또는 메뉴의 **이용 가이드**에서 같은 안내를 읽을 수 있습니다. 웹 안내 경로는 `/guide.html#member`입니다. 로그인 없이 읽고 검색할 수 있으며 **회원 안내 인쇄**로 전체 회원 안내를 인쇄할 수 있습니다.

## 1. 가입과 첫 승인

1. 매장에서 받은 예약 주소나 QR을 열고 **회원 가입**을 누릅니다.
2. 이름, 연락처, 아이디와 비밀번호를 입력하고 **가입 신청**을 누릅니다.
3. 첫 가입은 **승인 대기**입니다. 사장님이 승인한 후 예약할 수 있습니다. **승인 상태 확인**으로 다시 확인합니다.
4. 이후에는 같은 아이디와 비밀번호로 로그인합니다. 매번 가입하거나 다시 승인받지 않아도 됩니다.

아이디는 영문·숫자·밑줄(_) 4–32자이며 대소문자를 구분하지 않습니다. 비밀번호는 12–128자입니다. 1회용 초대 링크로 가입해도 첫 승인은 필요합니다. 신규 가입을 쉬는 동안에도 기존 회원은 로그인할 수 있습니다.

## 2. 날짜와 시간 선택

1. **예약하기**에서 날짜를 고릅니다. 매장에서 정한 예약 공개 기간 안의 날짜를 선택할 수 있습니다.
2. **예약 가능** 시간 중 하나를 선택합니다. 한 예약은 30분입니다.
3. 필요한 메모를 적고 **예약 내용 확인**을 누릅니다.
4. 날짜와 시간을 확인하고 **예약 확정하기**를 누릅니다.
5. **내 예약**에 확정 내역이 나타나는지 확인합니다.

확정 내역은 **내 예약**에서 확인합니다. 문자·카카오 알림은 자동으로 보내지 않습니다. 모든 날짜와 시간은 서울 기준입니다. 같은 시간은 한 분만 예약할 수 있습니다. 화면에서 선택했더라도 다른 사람이 먼저 확정하면 저장되지 않습니다. 안내를 확인하고 다른 시간을 선택합니다.

휴무, 운영자 차단, 이미 예약된 시간, 지난 시간, 하루 예약 한도에 도달한 시간은 선택할 수 없습니다.

## 3. 내 예약 조회, 메모 수정과 취소

**내 예약**에서 조회 시작일과 종료일을 정하고 **기간 조회**를 누릅니다. 본인 계정에 연결된 예약만 보입니다.

- **메모 수정**으로 전달할 내용을 바꾸고 **변경 내용 저장**을 누릅니다.
- **예약 취소**에서 내용을 확인하고 필요하면 사유를 적은 뒤 **예약 취소하기**를 누릅니다.
- 날짜나 시간을 바꾸려면 기존 예약을 취소하고 새로 예약하거나 매장에 문의합니다. 취소 후 원하는 새 시간의 예약을 보장하지는 않습니다.

취소와 메모 수정은 매장에서 정한 취소 마감 전까지만 가능합니다. 정확한 마감은 **예약하기 → 나의 예약** 아래 안내를 확인합니다. 마감 시각에 도달했거나 버튼이 보이지 않으면 매장에 문의합니다.

## 4. 예약이 보이지 않거나 오류가 날 때

- **새로고침**을 누르고 조회 기간이 맞는지 확인합니다. 화면을 보고 있을 때는 30초마다 갱신됩니다.
- 연결 오류 안내가 나오면 최신 상태가 아닐 수 있습니다. 연결을 확인하고 다시 불러옵니다.
- 전화·현장 예약은 사장님이 회원 계정에 연결한 경우에만 **내 예약**에 보입니다. 연락처가 같아도 자동 연결되지 않습니다.
- **승인 대기**라면 승인 상태를 확인합니다. **이용 중지**나 **가입 거절** 안내가 나오면 사장님에게 문의합니다.

## 5. 비밀번호와 기존 접속키

비밀번호를 잊었다면 사장님에게 문의합니다. 본인 확인 후 받은 재설정 링크를 열어 새 비밀번호를 직접 정합니다. 링크는 24시간 동안 한 번 사용할 수 있습니다. 만료되면 새 링크를 요청합니다.

현재 비밀번호를 안다면 메뉴의 **비밀번호 변경**을 사용합니다. 변경하면 다른 기기의 로그인은 종료됩니다. 예전 접속키를 쓰던 회원은 로그인 화면의 **예전 접속키로 시작**에서 아이디와 비밀번호를 한 번 설정할 수 있습니다. 전환 후에는 기존 접속키를 사용하지 않습니다.

비밀번호나 재설정 링크를 다른 사람에게 전달하지 않습니다. 매장 관리자는 앱에서 회원 비밀번호를 조회할 수 없습니다.

## 6. 다른 회원에게 보이는 정보와 QR 이용

회원들은 같은 예약 가능 현황을 보지만 다른 회원의 이름·연락처·예약 메모는 볼 수 없습니다. 본인은 내 예약에서 본인 예약을 보고, 사장님은 회원 확인과 일정 관리에 필요한 정보를 확인합니다.

웹 안내 카드에서는 예약 주소를 눌러 열거나 복사하고 QR을 스캔할 수 있습니다. PNG로 저장한 안내 카드는 이미지라서 주소 클릭·복사 기능이 없습니다. 같은 휴대폰에서 예약할 때는 함께 받은 예약 링크를 누릅니다.

도움이 필요하면 앱에 표시된 매장 문의 연락처로 연락합니다. 비밀번호를 보내는 대신 오류 문구와 발생 시각을 알려 줍니다.
