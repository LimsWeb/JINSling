공유 PNG는 재사용하는 공용 예약 URL과 7일·가입 1회용 초대 URL을 구분해 구현했습니다. 외부 QR 서비스 없이 로컬에서 생성하며, 실물 휴대폰 확인은 남아 있습니다.

## 이전 브라우저 확인 — 2026-10-30

Sites 관리형 미리보기와 실제 로컬 API·SQLite에서 **가상 회원·전화번호·예약만** 사용했습니다. 기존 가상 키 계정을 삭제하지 않고 아이디·비밀번호로 전환한 상태입니다.

| 흐름 | 관찰한 결과 |
|---|---|
| 가입 화면 | 이름·전화번호·아이디·비밀번호·확인 입력, 이메일 입력 없음 |
| 승인 대기 회원 | 계정 아이디와 대기 상태 표시, 예약 화면 접근 없음 |
| 승인된 회원 | 체험 버튼의 아이디·비밀번호 로그인 후 별도 승인 없이 예약 화면 접근 |
| 회원 관리 | 아이디·이름·전화번호·상태·가입일·초기화 버튼, 회원 CSV 링크 표시 |

실제 비밀번호 입력·초기화 완료와 병렬 요청의 상세 검증은 위 자동 테스트로 수행했습니다. 브라우저에서 새 실제 계정을 만들거나 사용자의 인증정보를 입력하지 않았습니다. 실제 제공자 재설정·실물 휴대폰·운영 HTTPS 쿠키는 배포 후 확인합니다. 개발 HTTP 프리뷰에서만 임시 쿠키 변환을 쓰며 운영 Secure/HttpOnly/SameSite 정책은 유지합니다.

## 이전 독립 검토 — 2026-10-30

구현 담당과 별도의 검토자가 인증 제공자·계정 API·SQL 마이그레이션·복구 도구·UI·최종 배포 및 소유권 문서를 검토하고 통합51개 테스트를 별도로 실행했습니다. 이미 열린 탭에서 초기화 링크의 fragment만 바뀔 때 화면 전환이 누락될 수 있던 문제를 찾아 수정했습니다. fragment 즉시 제거, 늦은 응답 무시, 더 새 링크의 흐름 보존을 보조 로직 테스트로 확인했습니다.

검토 범위에서 미해결 중대 보안·정확성 문제는 발견되지 않았습니다. 이는 무결점이나 보안 인증을 의미하지 않습니다. 제공자 변경과 DB 저장은 한 트랜잭션이 아니며 결과가 불확실하면 계정을 잠그고 문서화한 소유자 복구를 요구합니다.
