# jinSling 사장님 이용 가이드

로그인 화면 또는 메뉴의 **이용 가이드**에서 같은 안내를 읽을 수 있습니다. 웹 안내 경로는 `/guide.html#owner`입니다. **안내에서 찾기**로 검색하고 **사장님 안내 인쇄**로 선택한 안내 전체를 인쇄할 수 있습니다. 안내는 로그인 없이 열리며 실제 회원·예약 자료를 포함하지 않습니다.

사장님은 앱에서 회원 승인과 일정을 관리하고, 유지보수 담당자가 배포·클라우드 유지보수·백업을 맡습니다.

예약은 30분 단위이며 모든 날짜와 시간은 서울 기준입니다. 매장에서 정한 영업시간, 하루 예약 한도와 예약 공개 기간이 적용됩니다.

## 1. 회원 승인과 이용 상태

1. 관리자 계정으로 로그인하고 **회원 관리**를 엽니다.
2. **승인 대기** 회원의 이름과 연락처를 확인한 뒤 **승인**을 누릅니다.
3. 승인된 회원은 같은 아이디와 비밀번호로 로그인해 직접 예약합니다. 첫 가입 때 한 번만 승인하면 됩니다.
4. 필요하면 **이용 중지**, **이용 재개**, 승인 대기 회원의 **가입 거절**을 사용합니다.

입력된 연락처 자체가 본인 인증을 뜻하지는 않으므로 가입 정보를 확인합니다. 회원 상태 변경과 예약 취소는 별개입니다. 기존 예약까지 정리해야 한다면 예약 일정에서 확인하고 별도로 처리합니다.

**운영 설정 → 새 회원 가입 받기**를 끄면 신규 가입만 중단됩니다. 기존 회원의 로그인과 예약은 계속됩니다. 등록 계정 한도에는 관리자와 승인 대기·이용 중지·가입 거절 계정도 포함됩니다.

## 2. 전체 예약 확인과 변경

**예약 일정**에서 **다가오는 예약**, **하루 보기**, **7일 보기**로 전체 손님 예약을 봅니다. 화면을 보고 있을 때 목록은 30초마다 갱신됩니다. 연결 오류가 나면 최신 상태를 확인하지 못한 것이므로 새로고침합니다.

- **일정 · 메모 변경**: 날짜, 시작 시간, 고객 이름, 연락처와 메모를 수정합니다. 저장할 때 예약 겹침과 운영 규칙을 다시 확인합니다.
- **예약 취소**: 예약과 취소 사유를 확인한 후 취소합니다. 손님과 일정 변경을 먼저 조율합니다.
- **내 계정 예약**: 관리자 본인 계정으로 잡은 예약만 표시됩니다. 손님 전체 예약은 **예약 일정**에서 확인합니다.

문자·카카오 알림은 자동으로 보내지 않습니다. 사장님의 관리 기능은 회원의 취소 마감 후에도 사용할 수 있습니다. 다른 사람이 먼저 수정했다는 안내가 나오면 새로고침한 뒤 최신 내용을 확인합니다.

## 3. 전화·현장 예약 등록

1. **예약 일정 → ＋ 수기 예약**을 누릅니다.
2. 기존 회원이면 **회원 연결**에서 정확한 계정을 선택합니다. 연결한 예약은 해당 회원의 **내 예약**에도 표시됩니다.
3. 회원이 아니라면 **전화 · 현장 고객 (계정 연결 없음)**으로 두고 이름과 연락처를 입력합니다.
4. 날짜, 시작 시간과 메모를 확인하고 **예약 등록하기**를 누릅니다.

연락처가 같아도 자동으로 계정에 연결되지 않습니다. 수기 예약도 30분 단위이며 영업시간, 예약 겹침, 하루 한도를 검사합니다.

## 4. 하루·반나절 휴무 잠금

**운영 설정 → 휴무 · 시간 잠금 → ＋ 휴무 잠금**에서 등록합니다.

| 선택 | 날짜마다 잠기는 시간 |
|---|---|
| 하루 | 00:00–24:00 |
| 오전 | 00:00–12:00 |
| 오후 | 12:00–24:00 |
| 직접 지정 | 30분 단위 선택, 종료는 24:00까지 |

1. 시작일과 종료일을 선택합니다. 양 끝 날짜를 포함해 최대 31일이며 오늘부터 365일 후까지 등록할 수 있습니다.
2. 시간대와 필요하면 잠금 메모를 입력합니다.
3. **잠금 내용 미리보기**를 눌러 기간, 시간, 대상 날짜와 예약 겹침을 확인합니다.
4. 겹치는 예약이 없다면 **확인한 내용으로 잠금 저장**을 누릅니다.

예약과 겹치면 날짜와 시간을 표시하고 **전체 잠금을 거절**합니다. 일부 날짜만 저장하거나 예약을 자동 취소하지 않습니다. 날짜·시간을 바꾸거나 손님과 조율해 예약을 별도로 처리한 후 다시 시도합니다. 미리보기 후 새 예약이 생겨도 저장할 때 다시 검사합니다.

내용을 수정하면 미리보기를 다시 확인해야 합니다. 통신 오류로 저장 결과가 불확실하면 같은 창에서 같은 내용으로 다시 저장할 수 있습니다. 같은 요청 번호를 사용해 중복 등록을 막습니다.

## 5. 잠금 해제

**운영 설정 → 휴무 · 시간 잠금**에는 오늘부터 365일 후까지의 잠금이 표시됩니다.

- **묶음 해제**: 해당 등록 묶음의 남은 잠금을 모두 해제합니다.
- **날짜별 잠금 보기 · 개별 해제 → 이 날짜 해제**: 해당 날짜의 잠금 하나만 해제합니다.
- 기존에 따로 등록한 단일 잠금도 **이 날짜 해제**로 해제합니다.

다른 묶음이나 개별 잠금과 겹친 경우 하나를 해제해도 다른 잠금은 그대로 남습니다. 요일 휴무, 영업시간, 기존 예약과 하루 한도도 유지됩니다. 해제 후 **예약하기**에서 실제 예약 가능한 시간을 확인합니다.

## 6. 운영 설정

**운영 설정**에서 기본 안내와 요일별 영업시간을 바꾼 후 **운영 설정 저장**을 누릅니다.

- 매장 이름과 공개 문의 연락처
- 예약 공개 기간과 고객 취소 마감
- 등록 계정 한도와 신규 가입 여부
- 요일별 휴무, 영업 시작·종료 시간, 하루 예약 한도

공개 문의 연락처는 관리자 개인 연락처와 별개입니다. 고객에게 안내할 번호만 입력하고, 필요 없으면 비워 둡니다. 빈 시간 칸이 있어도 하루 한도에 도달하면 더 예약받지 않습니다. 이미 확정된 예약과 충돌하는 휴무·영업시간·하루 한도 변경은 저장할 수 없습니다.

## 7. 예약 안내 카드, 링크와 QR

**회원 관리 → 예약 안내 · QR**을 엽니다.

- 여러 사람에게 계속 안내하려면 공용 예약 주소 또는 **안내 카드 링크 복사**를 사용합니다.
- 웹 안내 카드에서는 예약 주소를 눌러 열거나 복사하고 QR을 스캔할 수 있습니다.
- **이미지 저장 (PNG)**은 인쇄하거나 보여줄 이미지입니다. PNG 안의 주소는 클릭·복사 버튼이 아니므로 메시지에는 클릭할 링크도 함께 보냅니다.
- **＋ 1회용 초대**는 한 사람에게 전달하는 링크입니다. 7일 동안 한 번 사용할 수 있고, 사용 전 철회할 수 있습니다. 같은 초대를 여러 사람에게 전달하지 않습니다.

어느 방법으로 가입해도 첫 승인은 필요합니다. QR을 인쇄한 뒤 휴대폰으로 정확한 예약 주소가 열리는지 확인합니다.

## 8. 비밀번호 재설정 지원

**회원 관리**에서 요청한 회원의 이름·아이디·연락처를 확인하고 **비밀번호 재설정**을 누릅니다. 한 번 표시되는 링크를 해당 회원 본인에게 안전하게 전달합니다. 회원이 새 비밀번호를 직접 정합니다.

링크는 24시간 동안 한 번 사용할 수 있습니다. 비밀번호 조회 기능은 없습니다. 현재 비밀번호를 아는 사장님은 메뉴의 **비밀번호 변경**을 사용할 수 있습니다. 관리자 계정에 로그인할 수 없고 재설정 링크도 없으면 유지보수 담당자에게 계정 복구를 요청합니다.

비밀번호나 재설정 링크를 공개 안내, 공용 채팅, 저장소에 올리지 않습니다.

## 9. CSV 내보내기와 백업

- **회원 관리 → 회원 CSV 다운로드**: 회원 목록을 내려받습니다.
- **기록 · 내보내기 → 예약 CSV 다운로드**: 조회 시작일·종료일을 정해 예약 자료를 내려받습니다.
- **기록 · 내보내기 → 최근 변경 기록**: 최근 100건과 변경 내용을 확인합니다.

CSV에는 이름·연락처 등 개인정보가 포함되므로 업무에 필요한 담당자만 접근할 수 있는 곳에 보관합니다. 비밀번호나 재설정 링크는 내려받을 수 없습니다.

CSV는 내려받은 시점의 자료이며 시트에서 수정해도 앱으로 자동 반영되지 않습니다. 전체 서비스 복구용 백업을 대신하지 않습니다. 현재 운영 방식에서는 유지보수 담당자가 운영 데이터 백업과 복구를 담당합니다. 복구 전에 대상 시점과 범위를 함께 확인합니다.

회원은 다른 회원의 이름·연락처·예약 메모를 볼 수 없습니다. 앱의 회원·예약 관리 기능은 사장님 계정에서 사용합니다. 클라우드 유지보수 권한의 범위는 [회원 정보와 운영 권한](OWNER_DATA.md)을 참고합니다.
