# 사장님 사용 안내

## 처음 한 번

전달받은 실제 운영 주소를 열고 사장님 아이디·비밀번호로 로그인합니다. 아이디는 영문·숫자·밑줄 4–32자이며 대소문자를 구분하지 않습니다. 비밀번호는 15–128자이고 한글·띄어쓰기를 사용할 수 있습니다. 긴 문장 형태로 만들고 비밀번호 관리자의 저장 기능을 이용할 수 있습니다.

처음 설정은 평일 09–20시/18건, 토요일 09–14시/10건, 일요일 휴무, 1회 30분입니다. 평일에는 가능한 시간이 22칸이지만 예약은 18건까지만 받습니다. 점심시간은 자동으로 정하지 않았으므로 실제 쉬는 시간을 직접 막아주세요.

설정의 **공개 매장 연락처**는 선택 사항입니다. 최초 등록 때 입력한 사장님의 개인 전화번호가 자동으로 공개되지 않습니다.

## 회원 가입과 한 번의 승인

1. 손님이 사이트에서 이름·전화번호·아이디·비밀번호를 입력해 가입을 신청합니다. 이메일 주소나 문자 인증은 필요하지 않습니다.
2. 사장님이 회원 관리에서 신청자를 확인하고 승인합니다. 입력된 전화번호 자체가 본인 인증을 뜻하지는 않습니다.
3. 승인된 손님은 밤에도 사장님의 추가 확인 없이 로그인하고 본인 예약을 조회·등록합니다.

**첫 가입이 아직 승인되지 않았다면** 손님은 로그인해 대기 상태를 볼 수 있지만 예약은 할 수 없습니다. 밤에 처음 신청한 사람은 사장님이 확인한 뒤 이용합니다. 매번 접속을 허가하는 구조가 아닙니다.

운영 설정에서 새 가입 접수를 닫을 수 있습니다. 기존 승인 회원은 계속 이용할 수 있습니다. 초대 링크도 선택적으로 사용할 수 있지만 기본 가입에 필수는 아닙니다. 이용 중지·가입 거절은 해당 계정의 기존 로그인도 종료합니다.

회원 등록 한도는 기본 **100명**, 설정상 **최대 1,000명**입니다. 관리자와 승인 대기·이용 중지·거절 계정도 포함합니다. 처음 4–5명 시험은 사용성을 확인하는 단계이며 전체 정원이 아닙니다. 주 70회 방문, 하루 18/10건 예약, 등록 계정 수는 각각 다른 수치입니다. 1,000명은 앱 설정 상한이며 실제 무료 처리량 보증은 아닙니다.

## 비밀번호를 잊어버렸다면

회원 관리에서 본인인지 확인한 뒤 **비밀번호 초기화**를 누릅니다. 화면에 한 번 나오는 링크를 그 회원에게 직접 전달합니다. 자동 문자·이메일은 보내지 않습니다.

링크는 발급 후 24시간 동안 한 번 사용할 수 있습니다. 링크를 받은 회원이 새 비밀번호를 정합니다. 사장님은 원래 비밀번호나 새 비밀번호를 볼 수 없습니다. 발급 즉시 그 회원의 기존 로그인이 종료되며, 초기화를 마칠 때까지 이전 비밀번호로 로그인할 수 없습니다. 승인 상태와 예약 기록은 그대로입니다.

새 링크를 다시 발급하면 이전 링크는 무효가 됩니다. 초기화 처리 중이라는 안내가 나오면 먼저 끝날 때까지 기다립니다. 인증 서비스 오류 뒤에도 잠금이 계속되면 DB를 임의로 지우지 말고 [소유자 복구 절차](DEPLOY_FREE.md#계정-분실과-중단된-비밀번호-처리-복구)를 따릅니다.

로그인한 회원은 계정 메뉴에서 현재 비밀번호를 확인하고 직접 변경할 수도 있습니다. 변경하면 다른 기기에서 사용하던 기존 로그인은 종료됩니다. 사장님 본인 비밀번호를 잃어버린 경우에는 사장님 소유의 Cloudflare 계정으로 복구합니다.

기존 접속키 방식으로 이미 만든 계정은 그 키로 한 번 로그인해 아이디·비밀번호를 정하면 됩니다. 같은 회원번호·승인 상태·예약 기록을 유지하며 전환 후에는 예전 키를 사용할 수 없습니다.

## 전화 예약과 하루 업무

관리자 일정 화면에서 오늘 예약을 확인하고 전화 예약을 추가합니다. 이미 가입한 회원은 목록에서 선택하면 그 회원에게 연결된 예약으로 등록할 수 있습니다. 회원이 아닌 전화 손님도 이름과 전화번호로 수기 예약할 수 있습니다. 비회원 수기 예약은 나중에 같은 전화번호로 가입했다고 자동으로 합쳐지지 않습니다.

휴식·개인 일정은 운영 설정에서 시간을 차단합니다. 특정 날짜 전체를 쉬려면 그날 영업시간 전체를 차단합니다. 다른 고객 예약과 겹치는 시간에는 전화 예약도 들어가지 않습니다. 이미 예약된 시간을 막으려면 해당 예약을 먼저 이동하거나 취소합니다.

이 앱은 문자·카카오 알림을 자동으로 보내지 않습니다. 일을 시작하기 전과 일정이 바뀐 뒤 화면을 새로고침해 신규 예약을 확인합니다.

## 예약 변경과 취소

사장님은 예약을 선택해 날짜·시간을 이동하거나 취소할 수 있습니다. 다른 예약이 있는 시간, 쉬는 시간, 하루 한도가 찬 날짜로 옮기면 변경이 거절되고 원래 예약이 유지됩니다. 오래 열어 둔 화면에서 충돌 안내가 나오면 최신 일정을 확인한 뒤 다시 처리합니다.

손님은 본인 예약을 확인하고 설정된 취소 기한까지 취소할 수 있습니다. 기본 취소 기한은 예약 시작 전입니다. 고객의 날짜·시간 이동은 사장님이 처리합니다. 취소는 삭제 대신 기록으로 남고, 변경 기록에서 담당자와 시각을 확인할 수 있습니다.

요일별 영업시간·정기 휴무·하루 예약 한도도 설정에서 바꿉니다. 이미 있는 예약을 무효로 만드는 변경은 거절됩니다. 하루 한도에는 이미 방문 시간이 지난 확정 예약도 포함됩니다. 오늘 확정 예약 수보다 낮게 한도를 바꾸려면 다음 날 적용합니다. 시간 차단은 앞으로 365일까지 등록·조회합니다. 현재 화면의 종료 시각 입력은 23:30까지입니다.

## 회원 정보와 기록 보관

회원 관리에서 이름·전화번호·아이디·가입일·승인 상태·비밀번호 초기화 상태를 볼 수 있습니다. 회원 CSV를 내려받아 **사장님 본인의 비공개 Google Sheet**에 가져올 수도 있습니다. 비밀번호·초기화 링크는 CSV에 들어가지 않습니다. 시트를 수정해도 앱 회원 정보가 바뀌지는 않습니다.

예약 CSV도 별도로 제공합니다. CSV는 업무 확인용이며 계정·권한·변경 기록까지 복원하는 전체 백업은 아닙니다. 백업과 운영 계정은 사장님이 보관하고 개발자에게 실제 고객 명단을 보내지 않아도 됩니다. 문제가 있으면 오류가 발생한 동작·시각·개인정보를 가린 화면을 전달합니다.

## 첫 4–5명 시험

휴대폰에서 가입 → 승인 → 재로그인 → 예약 → 화면을 닫고 다시 조회를 해봅니다. 사장님이 로그인하지 않은 시간에도 승인된 회원이 이용되는지 확인합니다. 서로 같은 시간을 골랐을 때 하나만 확정되는지, 전화 예약·시간 차단·이동·취소가 실제 업무와 맞는지 확인합니다. 초기화 링크가 한 번만 작동하는지도 함께 확인합니다.

가상 예약인지 실제 방문 예약인지 참여자끼리 정해 혼동을 막습니다. 개발 미리보기의 체험 계정은 운영 사이트에 포함되지 않습니다. 실제 Cloudflare·Firebase 연결과 휴대폰 확인이 끝난 뒤 본격적으로 사용합니다.
