# 휴무 일괄 관리, 이용 가이드와 별도 AI 실험판

사용자 요청: 현재 파일럿에 하루·반나절 단위 잠금/해제와 이용자 매뉴얼을 추가한다. 사장님의 일정·회원 관리 및 회원의 채팅 예약 AI는 기존 배포와 분리된 새 실험 프로젝트로 만든다. 비용은 0원이어야 하며 운영용 로컬 서버는 두지 않는다.

## 구현 결정

- 현재 파일럿은 Cloudflare Pages+D1/Firebase 계정 구조를 유지한다. AI 실험판은 독립 실행·빌드·배포 설정을 가진 `ai-lab/` 프로젝트로 보관하며 현재 `web/dist`나 운영 ZIP에 포함하지 않는다. 별도 배포 이름·DB, 가상 회원만 사용한다.
- 잠금은 하루(00:00–24:00), 오전(00:00–12:00), 오후(12:00–24:00), 직접 지정으로 제공한다. 반나절 경계는 명확한 낮 12시를 기본값으로 선택했다. 날짜 범위를 선택하면 최대 31일을 한 번에 처리한다. 오늘부터 365일 이내만 등록한다.
- 기존 예약과 겹치면 날짜·시간을 미리 보여주고 전체 잠금을 거절한다. 예약을 자동으로 취소하거나 일부 날짜만 조용히 처리하지 않는다. 기존 DB 트리거와 D1 batch 트랜잭션이 경쟁 요청도 방어한다.
- 새 일괄 잠금은 UUID 기반 묶음 ID를 각 block ID에 포함한다. 기존 스키마 변경 없이 묶음을 해제할 수 있다. 기존 단일 잠금과 별도로 등록한 다른 묶음은 유지한다. 반복 요청은 같은 요청 ID로 재처리하지 않는다.
- 가이드는 로그인 전에도 열 수 있는 `/guide.html`에 회원/사장님 탭, 실제 기능 기준 단계별 설명, 찾기, 인쇄를 제공한다. 사이트 메뉴 및 로그인 화면에서도 연결한다. 안내 자체는 공개지만 관리자 API 권한은 유지한다.
- AI 실험판은 모델이 명령을 제안하고 서버가 검증하는 구조다. 권한은 서버가 로그인 세션으로 판단하며 모델/브라우저의 role·user_id를 신뢰하지 않는다. 변경은 확인 버튼 후 실행한다. 실험판은 무료 한도 내 AI 제공자와 명시적인 모의 대화 모드, 서버 사용량 상한을 둔다. 운영 DB/인증 프로젝트를 연결하지 않는다.

## 대안과 선택 이유

예약이 있는 시간까지 자동 취소하는 잠금은 의도하지 않은 예약 취소 위험 때문에 제외했다. 날짜마다 기존 API를 반복 호출하는 방식은 중간 실패 시 일부만 잠기므로 전체 원자적 저장을 선택했다. 회원 안내를 GitHub 문서에만 두는 대신 앱에서 바로 열리는 가이드를 제공한다. AI를 운영 앱에 즉시 붙이는 대신 사용자 요청대로 독립 실험 프로젝트로 구현한다.

AI 무료 제공자와 모델은 공식 문서 조사 후 기록한다. 무료 제공자의 무제한·영구 무료를 보장하지 않으며 유료 자동 전환 경로는 구현하지 않는다.
